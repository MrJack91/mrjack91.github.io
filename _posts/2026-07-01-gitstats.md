Mit [gitstats](https://gitstats.readthedocs.io/en/latest/getting-started.html) lassen sich einfach paar Stats für ein Git Repo erstellen und im Browser ansehen.


```bash
docker run -it --rm --name gitstats-container -p 127.0.0.1:8000:8000 python:3.14.6-trixie bash

# in einem anderen Terminal
docker cp /repo/path gitstats-container:/app

pip install gitstats
git config --global --add safe.directory /app
gitstats . report
python3 -m http.server 8000 --bind 0.0.0.0 -d /app/report
```

Auf dem Host:
[localhost:8000](http://localhost:8000/)
